## 🐛 TROUBLESHOOTING

### Issue: Build Fails

**Possible Causes:**
1. Missing dependencies
2. Build errors in code
3. Environment variables not set

**Solution:**
\\\ash
# Test build locally first
npm run build

# If successful locally, check Vercel build logs
# Go to: Vercel Dashboard → Deployments → [Failed deployment] → Build Logs
\\\

---

### Issue: Site Loads but API Fails

**Possible Causes:**
1. VITE_API_URL not set
2. CORS not configured on backend
3. Backend not running

**Solution:**
1. Check environment variables in Vercel dashboard
2. Verify VITE_API_URL points to: https://care-integrity-api.onrender.com
3. Test API directly: https://care-integrity-api.onrender.com/health
4. Check Render backend is running

---

### Issue: Images Don't Display

**Possible Causes:**
1. R2 CORS not configured
2. Navigation state not passing
3. Component integration issue

**Solution:**
1. Check browser console for errors
2. Verify console shows: "Using updated profile from navigation state"
3. Check Network tab for failed R2 requests
4. Verify R2 bucket CORS allows your Vercel domain

---

### Issue: Deployment URL Not Working

**Possible Causes:**
1. Deployment still in progress
2. Build failed
3. DNS propagation (for custom domains)

**Solution:**
1. Check deployment status in Vercel dashboard
2. Wait for "Deployment Complete" status
3. For custom domains, allow 24-48 hours for DNS propagation
4. Use Vercel-provided URL first, then configure custom domain
