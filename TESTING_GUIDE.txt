## 🐛 TROUBLESHOOTING

### Issue: Image doesn't display after upload

**Possible Causes:**
1. Navigation state not passed correctly
2. Dashboard not checking location.state
3. R2 CORS issue

**Debug Steps:**
1. Open browser DevTools (F12)
2. Go to Console tab
3. Upload an image and save
4. Check for console logs:
   - Should see: "[CaregiverDashboard] Using updated profile from navigation state"
   - Should NOT see errors about image loading
5. Go to Network tab
6. Look for image requests
7. Check if R2 URLs return 200 OK
8. If CORS error, check R2 bucket CORS configuration

---

### Issue: Preview doesn't show selected image

**Possible Causes:**
1. File input not working
2. Blob URL creation failed
3. Browser security restrictions

**Debug Steps:**
1. Check console for errors
2. Verify file input onChange handler fires
3. Check photoPreview/logoPreview state in React DevTools
4. Try different image file

---

### Issue: Console shows "Loading profile from API" instead of navigation state

**Possible Causes:**
1. Navigation state not passed
2. location.state undefined
3. State cleared too early

**Debug Steps:**
1. Check CaregiverProfileEdit/AgencyProfileEdit handleSubmit
2. Verify navigate() call includes state parameter
3. Check dashboard useEffect dependencies include location
4. Inspect location.state in dashboard component
